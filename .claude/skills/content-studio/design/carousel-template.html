SESIONES Y CLI08/12

Las sesiones viajan. La CLI no.

  • Las sesiones se replican desde la región donde se originaron. El sign-out y la revocación también.
  • Un admin puede revocar sesiones desde una región adicional.
  • La autorización de la AWS CLI no se replica: armá un perfil "DR" por región.
[sso-session corp-dr] sso_start_url = https://ssoins-….eu-west-1.portal.amazonaws.com sso_region = eu-west-1
